# Kanban Board Screenshots

The course asks for screenshots of the board at the beginning, middle, and end of each sprint, to show progress.

Board: https://github.com/users/alafwaj/projects/2

How to take one:

1. Open the board. It should show columns (To do, In progress, In review, Done). If it shows a list, click the arrow next to the view name and choose **Board** under Layout.
2. Make sure every column is visible. Zoom the browser out if needed.
3. Press **Windows + PrtScn** so the picture includes the date and time in the taskbar. On a Mac, press **Shift + Command + 3** with the menu-bar clock showing.
4. Save the picture in this folder as `sprint-1-beginning-YYYY-MM-DD.png`, `sprint-1-middle-YYYY-MM-DD.png`, or `sprint-1-end-YYYY-MM-DD.png`, using the date it was really taken.
5. Fill in the table below and commit both files.

Take each screenshot on its day. A board cannot be photographed in the past.
